# Enterprise-GenAI-Suite

A collection of high-utility LLM tools developed for Session 2 Assignment.

## 🛡️ Guardrails & Accuracy
- **Zero-Hallucination Policy:** Prompts are engineered to cite sources directly and stick strictly to provided context.
- **Compliance Guardrails:** The Policy Checker uses JSON output for deterministic integration and does not invent laws.
- **Tone Consistency:** Role-based prompting ensures professional business standards for all generated text.

## 📦 Deliverables
- **Tool 1:** Executive Summary (Markdown + Metrics Table)
- **Tool 2:** Client Email (Formal Tone)
- **Tool 3:** Compliance Checker (JSON Schema)
- **Tool 4:** Meeting Summarizer (Decision Mapping)
- **Tool 5:** Market Analyst (SWOT + Trends)
